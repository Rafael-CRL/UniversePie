# Decisões

Uma decisão por arquivo, no formato [MADR](https://adr.github.io/madr/) enxuto:
contexto, decisão, consequências. Numeradas e imutáveis — uma decisão errada não
é editada, é **substituída** por outra que a referencia.

Só entra aqui decisão com consequência real e que pode ser revisitada. Registro
de decisão que vira papelada obrigatória depois do fato não serve para nada.
